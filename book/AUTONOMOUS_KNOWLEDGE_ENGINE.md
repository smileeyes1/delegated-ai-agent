# Autonomous Knowledge Engine v1

## Objective
Provide the missing knowledge-autonomy layer: the factory must create and resolve its own research tasks, not merely heartbeat.

## Autonomous cycle
1. Read durable state and all unresolved gates.
2. Generate the highest-value research tasks from explicit blockers and knowledge gaps.
3. Acquire evidence from configured authoritative sources.
4. Normalize evidence and provenance.
5. Verify source identity, quotation/reference integrity, and context.
6. Generate counter-search tasks against every material emerging claim.
7. Compare interpretations and preserve disagreement.
8. Score evidence sufficiency; block unsupported claims.
9. Build argument maps only from eligible evidence.
10. Draft bounded manuscript units with claim-to-evidence links.
11. Run independent critics: factual, source, contradiction, inference, structure, language.
12. Repair defects and rerun regression tests.
13. Checkpoint every artifact and state transition.
14. Select the next unresolved/high-value task automatically.

## Agent roles
- Researcher: finds evidence.
- Verifier: tries to falsify provenance and claims.
- Synthesizer: builds argument maps.
- Author: writes only from eligible evidence.
- Adversary: searches for counter-evidence and alternative readings.
- Editor: improves clarity without changing evidential status.
- Auditor: checks traceability and release gates.

Roles must produce separate artifacts so one generation cannot silently validate itself.

## Knowledge autonomy boundary
Autonomy means the system can decide what to investigate next and how to improve its manuscript. It does not mean the system is entitled to convert uncertainty into religious certainty. Contested or insufficiently evidenced conclusions remain explicitly unresolved and are escalated according to the project's sovereign gate.

## No-idle rule
If no task is executable, the engine must diagnose the blocker and create the smallest actionable recovery task. If all planned questions are exhausted, it must run a gap audit against the book's coverage map and create new research tasks rather than merely sleeping.

## Completion proof
Knowledge autonomy is proven only by a real run that: creates a research task without a user message, gathers traceable evidence, produces a bounded draft, runs adversarial review, repairs at least one defect or records that none exists, checkpoints state, and creates the next task automatically.
