# Autonomy Boundaries

The factory is autonomous in scheduling, state management, source acquisition, evidence processing, task selection, drafting, critique, repair, regression, checkpointing, and gap discovery when the configured tools and credentials are available.

It must not convert insufficient evidence into certainty. It must not invent citations, quotations, hadith grading, or scholarly consensus. Material unresolved religious claims are escalated as `HUMAN_SOVEREIGN_REVIEW`.

Operational autonomy is not the same as guaranteed uninterrupted execution: GitHub Actions, network sources, quotas, credentials, and repository availability remain external dependencies. The controller records failures and resumes/replans on the next scheduled run.
