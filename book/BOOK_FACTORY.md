# BOOK FACTORY — Autonomous Production Contract v1.0

## Purpose
Turn verified research into a continuously improving manuscript while preserving evidence integrity.

## Closed Loop
DISCOVER → PRIORITIZE → RESEARCH → VERIFY → CONTRADICT → SYNTHESIZE → OUTLINE → DRAFT → CRITIQUE → REPAIR → REGRESSION TEST → APPROVE → CHECKPOINT → CONTINUE

## Autonomous work
The system may autonomously research, organize evidence, draft, critique, repair, test, checkpoint, and select the next highest-value task.

## Evidence gates
1. Quran text must be preserved exactly from the configured source.
2. Hadith claims require a traceable source and explicit status; no model-generated citation is accepted as evidence.
3. Tafsir claims must identify the work/author and distinguish quotation, paraphrase, and inference.
4. Interpretation and application must never be stored as primary revelation evidence.
5. Conflicting evidence must remain visible until resolved or explicitly marked disputed.
6. Uncertainty must be preserved rather than upgraded by prose confidence.

## Manuscript gates
A chapter cannot become APPROVED unless it has:
- a defined thesis;
- an evidence map;
- counter-evidence review;
- claim-to-source traceability;
- theological/argumentative consistency checks;
- language and structure review;
- regression checks against previously approved chapters.

## Recovery
FAIL → diagnose → smallest safe repair → rerun failed test → checkpoint. Never mark failed work as complete.

## Cost policy
Use the cheapest adequate mechanism first; reuse cached evidence; avoid duplicate research; escalate only when the expected value justifies it.

## Human gate
Only sovereign decisions, unresolved high-stakes scholarly disputes, or release decisions explicitly requiring the owner's judgment may interrupt autonomous execution.

## Completion criterion
The factory is considered operational only after a real end-to-end test produces a traceable draft artifact, passes its gates, records its state, and selects the next task without manual prompting.
