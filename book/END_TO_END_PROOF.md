# End-to-End Execution Proof

This file defines the evidence required before claiming that autonomous book production is operational.

## Required evidence
- A real workflow run completed.
- A research artifact was produced with provenance.
- A bounded manuscript artifact was produced or revised.
- Quality gates ran and their results were persisted.
- State was checkpointed after the run.
- The next task was selected automatically.
- A failed check, if any, was repaired and re-tested rather than hidden.

## Status
`PENDING_RUNTIME_PROOF`

The repository must not claim continuous autonomous authorship until these conditions are observed in an actual run.
