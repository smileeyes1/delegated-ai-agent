# KNOWLEDGE COMPLETENESS CONTRACT

This contract governs what counts as real progress toward the book's mission.

## Required knowledge lifecycle
For every material research question:
1. Discover relevant Qur'anic corpus and authentic Sunnah evidence.
2. Preserve exact source references and source provenance.
3. Separate source text from tafsir, interpretation, inference, and application.
4. Search for counter-evidence and relevant scholarly disagreement.
5. Build a claim/evidence/argument map.
6. Record uncertainty and unresolved questions.
7. Only then permit synthesis into manuscript prose.

## Required durable artifacts
Each completed research unit must leave traceable artifacts for:
- source ledger
- claim ledger
- evidence ledger
- counter-evidence
- argument map
- uncertainty/open questions
- research run/checkpoint

## Coverage rule
The project may not enter a terminal state while any critical queue item is pending, blocked-retryable, unsupported, unverified, or missing required evidence artifacts.

## No false completion
Workflow success, file creation, model output, or passing technical tests are not intellectual completion. Completion requires substantive, traceable knowledge artifacts and all mandatory gates.

## Recovery rule
A blocked external dependency must create a durable retryable state and preserve all evidence already acquired. The next cycle must retry or choose a justified alternative path without fabricating evidence.

## Whole-book rule
After individual research units, run cross-unit synthesis audits for gaps, contradictions, duplicate claims, missing evidence, inconsistent terminology, and structural weaknesses. Final approval requires both unit-level and whole-book gates.
