# Autonomous Book Production Loop v1

## Purpose
Turn the project's research state into a continuously improving, evidence-controlled manuscript without treating generated prose as verified truth.

## Loop
1. Discover the highest-value unresolved question.
2. Research primary and high-quality secondary sources.
3. Record evidence with provenance.
4. Separate source, interpretation, inference, and application.
5. Search for counter-evidence and disagreement.
6. Build a defensible argument map.
7. Draft or revise one bounded chapter unit.
8. Run scholarly, factual, structural, and language critics.
9. Repair only identified defects.
10. Re-run regression checks.
11. Checkpoint state and artifacts.
12. Select the next highest-value task and continue.

## Non-negotiable gates
- No unsupported claim may become a verified claim.
- No generated hadith citation is accepted without provenance.
- Disagreement must remain visible when material.
- Failed validation does not advance the task.
- A chapter is not release-ready merely because it is fluent.
- Final religious claims require an appropriate human-sovereign gate when automated evidence is insufficient.

## Cost policy
Use the cheapest adequate method first; cache reusable artifacts; escalate only when the expected information gain justifies it; never repeat successful work without a reason.

## Recovery
Every stage writes durable state. A failed stage remains retryable. Repair attempts are bounded, auditable, and regression-tested.

## Completion proof
The system is considered operational only after an end-to-end run produces a traceable draft artifact, passes the applicable gates, checkpoints state, and selects a subsequent task without manual prompting.
