# مشروع الكتاب — Autonomous Book Engine

## الغاية
اكتشاف ما الذي يريد الله أن يصنعه الوحي في الإنسان، من القرآن والسنة الصحيحة، بمنهج نزيه لا يفترض النتيجة مسبقًا، ثم تحويل الاكتشاف إلى كتاب يحقق أثرًا حقيقيًا في الفهم والإيمان والعبادة والسلوك والحياة.

## وضع التشغيل
هذا المجلد هو مساحة الكتاب داخل المستودع `delegated-ai-agent`. لا يُعامل أي نص سابق بوصفه مرجعًا ملزمًا؛ بل مادة قابلة للاختبار.

## قواعد الحوكمة
- الحقيقة والدليل فوق البلاغة والانطباع.
- لا ادعاء بلا مصدر قابل للتتبع.
- فصل النص عن الفهم والتفسير والاستنتاج والتطبيق.
- لا استخدام لحديث ضعيف لإثبات دعوى مركزية.
- الخلاف المعتبر يُكشف ولا يُخفى.
- لا تثبيت لنتيجة قبل اختبار الأدلة المخالفة.
- لا تعديل تلقائي للنسخة النهائية على `main`؛ التغييرات تنتج Pull Request للمراجعة.
- القرارات السيادية فقط تُرفع للإنسان.

## دورة التشغيل
`STATE → NEXT TASK → RESEARCH → EVIDENCE → SYNTHESIS → QA → PR/REPORT → STATE`

## مبدأ الكلفة
الوكيل يعمل على مهمة واحدة صغيرة في كل تشغيل، يعيد استخدام السجل الموجود، ولا يعيد بحث ما تم تثبيته إلا عند ظهور دليل جديد أو تعارض.
